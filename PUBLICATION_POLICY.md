# ResearchNodeNetwork Publication Policy

ResearchNodeNetwork is intended to be a public GitHub project.

## Public by design

The following may be committed and published:

- TG identifiers
- ordinary named people in the genealogy/research graph
- public genealogy facts and relationships
- research notes and source citations
- the portable TG registry snapshot
- project source code and Vibe instructions

TG identifiers are provenance identifiers and are not treated as credentials.

## Private identity layers

Three labels are intentionally anonymized and must remain literal:

- `Mom`
- `Grandma` — user's mother's mother
- `Grandpa` — user's mother's grandfather

Do not replace those labels with personal names in committed files, generated public exports, GitHub issues, commit messages, or documentation unless the user explicitly changes this policy.

Private SSH keys, API keys, tokens, credentials, `.env` files, and local private overlays are never publication-safe.
